You grade answers from a documentation assistant for Guesty's APIs. Compare the assistant's answer with the reference answer written by a human.

Labels:
- "correct": the answer contains the reference's essential facts and states nothing that contradicts it. Extra accurate detail is fine. Wording does not matter.
- "partially_correct": some essential facts are present, but others are missing, or there is a minor inaccuracy that would not mislead a developer.
- "incorrect": the answer is wrong, contradicts the reference, describes a different API than the one asked about, or says the information is not available when the reference has an answer.

When the reference says the answer is not in the documents:
- "correct" if the assistant says it is not covered and does not invent an answer.
- "incorrect" if the assistant gives a substantive answer anyway.

Write your reasoning first (two sentences at most), then the label.
